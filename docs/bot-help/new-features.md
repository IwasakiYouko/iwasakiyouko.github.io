# 新功能速递

这里集中展示 HarukiCloud 近期新增或刚完善的功能，方便快速了解有什么新东西可以试。

## 2026 年 5-6 月

### 自定义个人信息

- 指令：`/自定义个人信息` `/cp`
- 用法：`/自定义个人信息 1`，或 `/自定义个人信息 u2 3`
- 说明：渲染游戏公开 profile 中的自定义个人信息页，每次渲染一张。`u序号` 可选择自己绑定列表中的账号。
- 详细说明：[个人资料与账号](/bot-help/account#自定义个人信息)

### 活动规划

- 指令：`/活动规划` `/pjsk event planner` `/event-planner`
- 用法：`/活动规划 pt1000w 当前pt120w 歌 虾ex 龙hd 5火 10火`
- 说明：结合目标 PT 或目标排名、当前 PT、歌曲、火数和活动组卡结果生成规划图。需要已上传 suite 数据。
- 详细说明：[活动查询](/bot-help/event#活动规划参数)

### 自定义谱面预览

- 指令：`/谱面预览` `/查曲` `/技能预览`
- 用法：`/jp谱面预览 <28位ID>`，或 `/jp查曲 <28位ID>`
- 说明：支持查询已发布自定义谱面的预览与详情。目前仅支持日服数据源，非日服默认绑定建议显式加 `/jp` 前缀。
- 详细说明：[音乐与乐曲](/bot-help/music#自定义谱面相关)
